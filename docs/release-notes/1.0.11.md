# com_biotime 1.0.11

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**New: Export PDF on the Manager Dashboard.** Under the employees table, **Export PDF** opens the
report in a new tab with the print dialog; choose **Save as PDF**. Every employee shown (all pages),
on your letterhead, with the filters, the cards and the table in the page's colours, and page
numbers. A4 portrait when the days fit (up to 6), landscape otherwise (longer periods are split
into tables of up to 12 days).

**Set up the letterhead once** in *Components → ZKBioTime → Integration Settings → Report
Letterhead*: the logo or letterhead banner (upload it in the Media Manager), the line of text on
each side under it, up to six footer lines (address, telephone, website, e-mail) and the main
colour. Without a logo the site name is shown.

**Fixed:** on the Manager Dashboard, a large white space could appear under the site footer once
data showed (with some site templates).
