# com_biotime 0.3.4 — new repository address

## Changed

The GitHub repository was renamed to **aboarken/joomla-biotime**. Joomla now checks
https://github.com/aboarken/joomla-biotime/releases/latest/download/updates.xml for updates and
reads the changelog from the same release. The extension is still `com_biotime`; settings and
mappings are kept.

Sites on an older version keep receiving updates: GitHub redirects the old `aboarken/biotime`
addresses. Installing 0.3.4 stores the new update server address.

No other changes and no database changes.
