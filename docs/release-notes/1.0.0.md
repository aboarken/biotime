# com_biotime 1.0.0

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Manager Dashboard** (new menu item): a manager sees everyone in their own department and the
  departments below it, with department, employee, status and date filters, cards for the
  workforce and the same figures as My Attendance, and one row per employee per day: check-in and
  check-out in one column, then Late In, Early Out and Total. Give the managers' group the new
  permission **View Manager Dashboard** (Options → Permissions) and add the menu item.
- **My Dashboard**: *Attendance rate per month* and *Your Devices* replace the circles chart; the
  period is always the school year, **1 August to 31 July** (it moves on by itself every 1 August).
- **Cards jump to the records** they filter, and My Attendance has an **All Days** card first to
  see every day again.
- **The explanatory note** under the pages and the "Updated" time are gone.
- **Database only**: the ZKBioTime REST API integration is removed (its settings, Test Connection
  and Find Endpoints). Test Database and the database settings stay; the stored API password is
  deleted on update.
