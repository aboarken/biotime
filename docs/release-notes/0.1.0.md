# com_biotime 0.1.0 — Stage 1: connection and authentication

This first version connects Joomla to ZKBioTime 9.5. It has **no portal pages yet**: it is for
checking, on the real server, that the portal can log in and read the Personnel API.

## What to do

1. Install `com_biotime.zip` on a Joomla 6.2 test site.
2. *Components → ZKBioTime → Integration Settings*: enter the server, port and a read-only API
   user; Save; **Test Connection**.
3. Work through the 0.1.0 section of the live checklist in `docs/TESTING.md` and send back:
   - the ZKBioTime **build number**;
   - the exports of `/api/docs/` and `/api/personnel_docs/`;
   - one sample JSON answer for the login and for the employee list (personal data removed);
   - the lines of `administrator/logs/com_biotime.php` from the test.

Stage 2 (employee mapping) starts once this is confirmed.

## Included

- Integration Settings with validation, encrypted password and token, TLS verification, CA bundle and certificate pin.
- Test Connection and Read Certificate Pin.
- The API client (JWT and General Auth Token, token renewal, paging, retries, error kinds, log without secrets).
- Permissions for the six future portal pages (not granted by default).
- MySQL/MariaDB and PostgreSQL; Joomla update server and changelog.

## Known limitations

- All ZKBioTime endpoints are **UNVERIFIED**: the build environment could reach neither the
  server nor the API manual. See `docs/API-MAPPING.md`.
