# com_biotime 0.3.2 — check-out from "Unknown" punches

## Fixed

Your terminals record punches as **Check In** (state 0) or **Unknown** (state 255); there are no
*Check Out* punches. When ZKBioTime's calculated times are not available, the portal now takes:

| | |
|---|---|
| Check-in | the first *Check In* punch (or, if there is none, the first *Unknown* punch that has a later punch) |
| Check-out | the last *Check Out* punch after it (or, if there is none, the last *Unknown* punch after it) |

So a day with *Check In 07:45* and *Unknown 15:20* shows 07:45 and 15:20. A lone check-out is
never shown as check-in; a lone *Unknown* punch is shown under neither and listed as incomplete.

## Changed

The punch list (`/iclock/api/transactions/`) and the employee list cannot be saved as the Daily
Attendance or Leave Source: the portal already reads them, and they contain no calculated
attendance. For the Daily Attendance Source choose ZKBioTime's calculated attendance endpoint
(one row per employee per day) in *Find Endpoints*.
