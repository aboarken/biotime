# com_biotime 1.1.0

Update from **System → Update → Extensions**, or install the attached package. No Joomla database
changes.

**Two new pages (menu item types), read only:**

- **My Leaves**: the employee's own leave requests from ZKBioTime, with the status and every
  approval stage (who approved or rejected it, when, and the remark).
- **My Approvals**: for approvers, the leave requests waiting at their stage in ZKBioTime, and the
  requests they have approved or rejected.

Requests are still made and approved in ZKBioTime, where the workflows and approvers are set up.
A Leave Request page is planned.

**Before using them:**

1. On the BioTime server, in pgAdmin as `postgres` on the `biotime` database, let the portal read
   the leave tables:

   ```sql
   GRANT SELECT ON att_leave, att_paycode, workflow_workflowinstance, workflow_nodeinstance,
     workflow_workflownode_approver, personnel_employee_flow_role
     TO joomla_portal;
   ```

2. *Components → ZKBioTime → Options → Permissions*: allow **View My Leaves** for employees and
   **View My Approvals** for approvers.
3. *Menus → Add New Menu Item → ZKBioTime*: **My Leaves** and **My Approvals**.
