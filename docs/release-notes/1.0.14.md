# com_biotime 1.0.14

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Organisation name on the PDF report**, set in the backend: *Components → ZKBioTime →
Integration Settings → Report Letterhead → Organisation Name*. It appears above "Attendance Report"
in the report's title band, at the top of the page when there is no logo (or under the logo with
*Show the Name with the Logo*), and at the start of the PDF's file name. Until it is set, Joomla's
site name is used, as before.
