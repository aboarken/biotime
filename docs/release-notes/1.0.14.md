# com_biotime 1.0.14

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Export PDF is always landscape**, with the **site name** at the top (Global Configuration →
  Site Name) and the *Attendance Report* band under it.
- **Total Late In and Total Early Out cards show only the time** (no number of days), on every page.

If you filled in *Integration Settings → Report Letterhead* (logo, header lines, footer) and do not
want them on the PDF, clear those fields there.
