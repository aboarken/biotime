# com_biotime 1.0.3

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Leaves** card on My Attendance, My Dashboard and the Manager Dashboard (and a Leaves status
  filter).
- **Days Present = present / (present + absent)**: leave days no longer count against anyone.
  **All Days** = Present + Absent + Leaves + Holidays + Weekend.
- **View all departments** (new permission): the Manager Dashboard shows every department. Super
  Users always have it; give it to your administrators' or HR group under Options → Permissions.
