# com_biotime 1.2.1

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**PDF report: even columns.** In the exported PDF the last three columns (Late In, Early Out and
Total Exceptions) took much more room than the days. The table now has fixed widths: the days share
the page equally, the three totals are only as wide as their titles need, and the employee column
has a set width in which long names wrap. On A3 a whole month fits in one table with every date
readable (a date breaks after a separator when the column is narrow, never inside a number).
