# com_biotime 1.0.10

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Security** (from a review of the whole component):

- The Manager Dashboard no longer uses the Joomla profile e-mail (which users can change) to
  find a manager's BioTime user: the employee ID and the employee record's e-mail only.
- **On the BioTime server, narrow the portal's database user to the tables it reads** (pgAdmin,
  as `postgres`, on the `biotime` database):

  ```sql
  REVOKE SELECT ON ALL TABLES IN SCHEMA public FROM joomla_portal;
  ALTER DEFAULT PRIVILEGES IN SCHEMA public REVOKE SELECT ON TABLES FROM joomla_portal;
  GRANT SELECT ON personnel_employee, personnel_department, personnel_position, personnel_resign,
    iclock_transaction, iclock_terminal, iclock_terminalemployee,
    att_attemployee, att_payloadbase, att_payloadtimecard, att_payloadpaycode, att_payloadattcode, att_payloadovertime,
    att_timeinterval, att_holiday, att_attshift, att_shiftdetail, att_attschedule, att_groupschedule,
    att_departmentschedule, att_temporaryschedule, att_tempschedule, auth_user_auth_dept
    TO joomla_portal;
  GRANT SELECT (id, username, email, emp_pin, is_active, is_superuser, can_manage_all_dept, del_flag) ON auth_user TO joomla_portal;
  ```

- Changing the database SSL mode or CA file asks for the database password again; database errors
  in the log no longer include the driver's text.

- **Faster pages**: the connection to the BioTime database stays open between pages, so pages no
  longer wait for a new encrypted connection each time. If the BioTime server restarts, the portal
  reconnects by itself.
- **Faster Manager Dashboard**: a manager's departments and team list are kept for the cache time
  (Integration Settings), so choosing a department no longer reads them again. Permission changes
  in BioTime show within that time.
- **Total Exceptions**: the late-in + early-out column on My Attendance and the Manager Dashboard.
- **Manager Dashboard: Workforce is the default card** (highlighted; it clears the chosen card).
