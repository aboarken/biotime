# com_biotime 1.0.10

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Faster pages**: the connection to the BioTime database stays open between pages, so pages no
  longer wait for a new encrypted connection each time. If the BioTime server restarts, the portal
  reconnects by itself.
- **Faster Manager Dashboard**: a manager's departments and team list are kept for the cache time
  (Integration Settings), so choosing a department no longer reads them again. Permission changes
  in BioTime show within that time.
- **Total Exceptions**: the late-in + early-out column on My Attendance and the Manager Dashboard.
- **Manager Dashboard: Workforce is the default card** (highlighted; it clears the chosen card).
