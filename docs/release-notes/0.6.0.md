# com_biotime 0.6.0 — pages from ZKBioTime's database

Update from **System → Update → Extensions**, or install the attached package. No database changes.

Turn it on in **Integration Settings → Database → Read attendance from: Database** (PostgreSQL).
The API stays configured and still matches employees.

- **Schedule applied each day**, **Late In** and **Early Out** per day, **Worked** time and overtime,
  as ZKBioTime calculated them.
- Monthly **Total Late In**, **Total Early Out** and **Late In + Early Out**, with the number of days.
- **Holidays** and **days off** in the schedule are no longer counted as Absent.
- My Dashboard shows the employee's department and position, and today's schedule and late in.
- My Attendance: new columns and filters (Late In, Early Out, Holiday). Calendar and day details
  show late and early too.

If late-in minutes look 60 times too large or too small, set *Duration unit* to Minutes or Seconds.
