# com_biotime 0.4.1 — new portal design

The portal pages (My Dashboard, My Attendance, Attendance Calendar, day details and Biometric
Devices) now use the same design as the ServiceDesk Plus portal:

- summary cards with a coloured edge, white panels with a title row, clean tables and coloured
  status pills (green Present, amber Incomplete, red Absent, grey Weekend, teal Checked In);
- month navigation (← November 2026 →) in the page heading;
- filters apply as soon as an option is chosen — no Show button;
- the calendar colours each day by its status; on phones each day shows a status symbol that the
  legend explains.

The portal styles everything itself, so the pages look the same on any site template.

No database or settings changes.
