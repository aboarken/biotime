# com_biotime 1.0.19

Update from **System → Update → Extensions**, or install the attached package. The update moves
users who are waiting for approval to their new status (no other database change).

**New setting: Integration Settings → Employee Mapping → New users.** The same choice as in the
ServiceDesk Plus portal:

- **Wait for administrator approval** (the default, unchanged behaviour): a user found by e-mail
  waits until you confirm them in *User Mappings*.
- **Approve automatically**: a user found by e-mail can use the portal at once. Users already
  waiting are approved on their next visit.

User Mappings now shows waiting users as **Waiting for approval** (filter Status), separately from
**Suspended** mappings.
