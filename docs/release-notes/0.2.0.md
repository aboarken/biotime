# com_biotime 0.2.0 — the complete portal

All six portal pages, employee mapping and exports in one release.

## Highlights

- **Six menu item types**: My Dashboard, My Attendance, Attendance Calendar, My Schedules,
  Attendance Reports (with PDF and Excel downloads) and My Profile.
- **Employee mapping** by the Joomla custom user field **employeeid** (= emp_code), then by
  e-mail; a **User Mappings** page to map by employee code, confirm, suspend and re-match.
- **Server URL with its port in one field**, e.g. `https://zkb.example.com:5555` (an existing
  separate port is merged automatically).
- **Your choice of ZKBioTime endpoint** for calculated attendance, per-day schedules and leave
  (Integration Settings → Daily Attendance Source / Leave Source), from your server's
  `/api/docs/`. Until it is set, those values show "—".

## After updating

1. *Users → Fields*: make sure only administrators can edit `employeeid`.
2. *Components → ZKBioTime → Options → Permissions*: allow the seven portal permissions for
   Registered.
3. *Integration Settings*: set the Daily Attendance Source (and Leave Source) from `/api/docs/`;
   Test Connection.
4. *Menus*: add the six menu items.
5. Work through the 0.2.0 section of `docs/TESTING.md` and send back the endpoint and field
   names used, so `docs/API-MAPPING.md` can mark them verified.
