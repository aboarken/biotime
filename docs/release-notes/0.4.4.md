# com_biotime 0.4.4 — clean-up, Note column

- **Recent Activity** on My Dashboard has a **Note** column with *! Missing Punch* for days whose
  check-in or check-out is missing.
- **Leave settings removed**: the Leave Source and the Leave information switch are gone from
  Integration Settings (leave has not been shown since 0.4.2, but a configured leave source was
  still read on every page). Updating deletes the stored leave settings.
- Code, strings and styles left over from removed features are cleaned up.

No database schema changes; all other settings and mappings are kept.
