# com_biotime 0.3.3 — one-click Diagnostics

## Added

**Diagnostics**, at the top of *Components → ZKBioTime → Find Endpoints*. Enter an employee code
(optional) and a period, click **Run Diagnostics**, then **Copy report** and send the text to
whoever supports the portal. It checks, from your Joomla server:

1. the connection (employee list);
2. the API list (`/api/docs/`, `/api/personnel_docs/`) and every list endpoint in it;
3. the punch endpoint `/iclock/api/transactions/` and its field names;
4. the calculated-attendance endpoints: attendance-like paths in the API list, plus
   `/att/api/totalTimeCardReport/` (documented in ZKTeco's BioTimeCloud API manual; **unverified**
   on ZKBioTime 9.5, which is what the check finds out).

The report contains only paths, results, row counts, field names, kinds of values and status
texts. No passwords, tokens, names, employee codes or times. Only GET requests are sent.

## Changed

If the API list contains no attendance, report or leave endpoints, Find Endpoints now says so
and points to Diagnostics.
