# com_biotime 1.0.8

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **The Manager Dashboard follows ZKBioTime's user permissions.** Managers need only *View
  Manager Dashboard*: each sees the departments their own ZKBioTime user (linked to their
  employee ID, or with the same e-mail) is permitted; a ZKBioTime superuser, or a user who may
  manage all departments, sees all.

  **Once, on the BioTime server** (pgAdmin, as `postgres`), let the portal read the
  needed columns of ZKBioTime's users, never the passwords:

  ```sql
  REVOKE SELECT ON auth_user FROM joomla_portal;
  GRANT SELECT (id, username, email, emp_pin, is_active, is_superuser, can_manage_all_dept, del_flag) ON auth_user TO joomla_portal;
  ```

- **The *View all departments* permission is removed**: give managers only *View Manager
  Dashboard*; who sees every department is set in ZKBioTime (superusers and users who may manage
  all departments).
- **Manager Dashboard**: Workforce comes before All Days, and the Employee ID example reads
  "e.g. EXXXX, then Enter".
