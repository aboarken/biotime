# com_biotime 1.0.2

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Manager Dashboard uses ZKBioTime's Department Manager**: a manager sees only the departments
  they are Department Manager of in ZKBioTime (and those below them). Anyone else sees "You don't
  have access to view departments in the Attendance Management System. Please contact the System
  Administrator."
- **Manager Dashboard**: Total Morning Punches and Total Afternoon Punches cards, and the table
  scrolls in its own box, so its sideways scrollbar is always visible.
- **My Dashboard**: Attendance rate per month as bars (red below 70 %, yellow 70–94 %, green from
  95 %), and faster loading of the school year.
- **A new month, year or date clears the chosen card.**
- **Log line timing** (Detailed logging): connect time, number of database queries and their time,
  and the page's total time.
