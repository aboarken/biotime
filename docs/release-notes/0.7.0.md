# com_biotime 0.7.0

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Fixed: past months showed no Late In and Early Out after the update to 0.6.3.** The previous
  version's copies of past months were kept in the cache for a day; an update now always reads the
  months again from ZKBioTime's database.
- **Device names without "Biometric - "** (e.g. "Main Gate").
- **My Dashboard no longer shows Recent Activity**; the days are in My Attendance and the calendar.

With 0.5.0–0.6.3 this completes reading attendance from ZKBioTime's database: schedules from the
shifts, Late In and Early Out from ZKBioTime's calculation, holidays, leave, and missing morning and
afternoon punches.
