# com_biotime 1.2.3

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**My Dashboard charts.**
- Every month under the charts now shows its **year** (Aug 2026 … Jan 2027), as the school year
  runs over two years. The year is written under the month's name so that all twelve months fit.
- In *Total Late In and Early Out per Month* (and *Missing Punches per Month*), a month with only
  one of the two values now has its column **centred above the month's name** (it stood to the left).
- *Attendance per Month* has a little more space above its legend, like the other cards.
