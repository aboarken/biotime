# com_biotime 0.6.2 — schedules from shifts

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Every day shows its schedule**, also today and later days: from ZKBioTime's calculation, else
  from the employee's (or group's, or department's) shift and temporary schedules.
- **Check-in / check-out cut-off from the timetable**: a punch before the end of the timetable's
  check-in window is the check-in, later punches the check-out (12:00 on days without a timetable).
- **Late In and Early Out come only from ZKBioTime's calculation**; the portal calculates nothing.
- **Colours**: weekends blue; holidays sky blue, with the whole row coloured.
- **Test Database → Shifts** lists your shifts' day numbers: if a schedule looks wrong, send that part.
