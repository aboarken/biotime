# com_biotime 0.5.0 — connect to ZKBioTime's database (first step)

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **New: Integration Settings → Database (direct read).** Connects to ZKBioTime's own database with
  a read-only user, for what the API does not give (schedules, calculated attendance, leave,
  holidays). This version adds the connection and **Test Database**; the portal pages still use
  the API.
- **Test Database** shows whether the connection is encrypted, whether the user really can only
  read, and the names of the tables and columns your server has, never any data. Copy its
  summary and send it, so the next version reads the right tables.
- The connection is read only on the Joomla side as well, the password is stored encrypted, and
  the `postgres` / `sa` administrator accounts are refused.

How to create the read-only user in pgAdmin: docs/DATABASE.md.
