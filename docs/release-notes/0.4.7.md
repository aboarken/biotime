# com_biotime 0.4.7 — security review and clean-up

Security
- **Administrator pages need Super User rights for every task**, not only from the menu.
- **The employee code field is checked**: if users can edit it themselves on their profile, the
  portal does not trust it (the user is shown as *not found* and a warning is logged). Allow
  editing of that field for administrators only.
- **A match found only after an e-mail change waits for an administrator** (shown as *suspended*
  in User Mappings).
- **Saved credentials never follow a new server address**: after changing the Server URL or
  *Connect via*, type the password (or token) again.

Fixed
- Old My Attendance links with the *Checked in* or *Holiday* filter no longer show an error.
- Months after the current one are no longer requested from ZKBioTime.

Removed
- Unused code, strings and outdated documentation.

No database changes. No settings change, except that the password must be re-typed when the
server address changes.
