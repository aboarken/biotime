# com_biotime 0.5.1 — database Server and Connect via, as for the API

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Integration Settings → Database (direct read):** host and port are one field, **Server**
  (e.g. `zkb-server.example.local:7496`), like the API's Server URL.
- New **Connect via** (PostgreSQL): the firewall's public IP and port Joomla really connects to,
  while the certificate is still checked against the Server name, the same as for the API.
  An IP address only. Changing it asks for the database password again.
