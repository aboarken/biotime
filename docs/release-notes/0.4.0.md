# com_biotime 0.4.0 — Biometric Devices, clear check-in/out, absent and weekend days

## What's new

- **Biometric Devices** — a new menu item type listing every ZKBioTime device with its name,
  location (area) and health (Online, Delayed, Offline), last activity and the users,
  fingerprints, faces and punches stored on it. Grant *View Biometric Devices* to the group that
  looks after the devices. *Show technical details* (menu item option) adds serial number, IP
  address and firmware.
- **Clear check-in and check-out** on My Dashboard, My Attendance, the Calendar and day details,
  each with the device and verification (fingerprint, face) it was recorded with, or *Missing*.
- **Absent and Weekend** — a past working day without any punch is *Absent*. Friday and Saturday
  are weekend days (*Integration Settings → System → Weekend days*); a weekend day with a
  check-in or check-out loses the weekend tag and is shown like any working day.
- **My Dashboard**: today's check-in and check-out, days attended / absent / incomplete, attendance
  rate, average check-in and check-out, time between them, weekend days worked.

## Removed

My Schedules, Attendance Reports (PDF/Excel) and My Profile, and the fields the ZKBioTime 9.5 API
does not provide (schedule, late-in, early-out, worked hours, overtime). ZKBioTime 9.5 has no API
for them, so they only ever showed "—".

## After updating

1. *Menus*: the menu items of the removed pages are in the trash. Add a **Biometric Devices**
   menu item if you want it.
2. *Components → ZKBioTime → Options → Permissions*: allow *View Biometric Devices* for the
   group that should see the devices.
3. *Integration Settings → System*: check *Weekend days*.

No database schema changes; settings and mappings are kept.
