# com_biotime 1.0.18

Update from **System → Update → Extensions**, or install the attached package. No database changes.

The whole component was audited against the Joomla Manual and for security
([docs/AUDIT.md](https://github.com/aboarken/joomla-biotime/blob/main/docs/AUDIT.md)). **No
critical, high or medium security problem was found.** This version tightens and tidies what the
audit listed:

- PDF reports: at most 30 per manager and hour, each recorded in the audit log.
- A manager's departments are kept for at most 5 minutes, so a permission removed in ZKBioTime
  stops showing quickly.
- No inline styles on the portal pages (works with a strict Content Security Policy).
- The unused *Modules → Charts* setting, old clean-up code and unused texts are removed.
