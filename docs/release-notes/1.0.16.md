# com_biotime 1.0.16

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Manager Dashboard: Export PDF (A3) and Export PDF (A4).** With **A3** the whole period, up to a
full month, is in one table, so every employee's days are on one row. **A4** works as before (up to
12 days per table). Both are landscape.
