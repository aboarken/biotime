# com_biotime 0.3.1 — Find Endpoints reads your server's API list

## Fixed

- **"ZKBioTime did not accept the request" on Find Endpoints.** Your ZKBioTime publishes its API
  list as CoreJSON and refused the request because the portal asked for plain JSON only
  (HTTP 406). The portal now asks for the CoreJSON format, so **Read the API list from
  ZKBioTime** lists your server's endpoints.

## Changed

- When reading the list or checking an endpoint fails, Find Endpoints shows ZKBioTime's own
  answer (HTTP status and message).
- A path that returns a web page instead of data is explained: it probably does not exist on
  the server (for example the test path `/att/api/fixture_daily/`, which only exists in the
  portal's own tests).

## After updating

1. *Find Endpoints → Read the API list from ZKBioTime.*
2. Select your daily attendance endpoint, **Check** it with one employee code and a week, review
   and **Save as Daily Attendance Source**. This replaces a wrong saved path.

## Verified on a real server

Login and the transaction list (`/iclock/api/transactions/` with `emp_code`, `start_time`,
`end_time`, rows under `data`) work on the ZKBioTime server; see `docs/API-MAPPING.md`.
