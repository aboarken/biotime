# com_biotime 1.2.6

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Pages open at once.** My Dashboard, My Attendance, the Calendar, day details and My Punches no
longer wait for ZKBioTime when their data is older than the cache time. They open at once with
the data they were last shown with, and a note above the title says so:

> Showing your data from Saturday, 21 November 2026 13:25. Updating…

Meanwhile the page reads current data in the background and replaces itself, usually within a
second or two; the note then disappears. If the user has already started choosing a filter, the
page offers *Reload the page* instead of changing under them. If ZKBioTime cannot be reached, the
page stays as it is and the note says *Could not update just now*.

Data older than 7 days is never shown this way. The Manager Dashboard, My Leaves and My Approvals
always read current data. The first visit (nothing kept yet) loads as before.
