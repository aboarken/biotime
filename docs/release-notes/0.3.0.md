# com_biotime 0.3.0 — Find Endpoints, and a check-in/check-out fix

## Find Endpoints

*Components → ZKBioTime → Find Endpoints* (or the **Find Endpoints** button on Integration Settings)
fills in the Daily Attendance Source and Leave Source for you:

1. **Read the API list from ZKBioTime.** The portal reads your server's API description
   (`/api/docs/`, `/api/personnel_docs/`) and lists its list endpoints, attendance, report and
   leave endpoints first.
2. **Select** an endpoint, enter one employee code and a short period, and **Check**. You see
   the field names, the kind of value in each (date, time, number, text) and the status texts
   found (e.g. Normal, Late, Absent). Names, codes, e-mails and other personal values are
   never shown.
3. **Review** the suggested field and status lines and **Save as Daily Attendance Source** (or
   Leave Source).

If your ZKBioTime does not publish a readable API list, open `/api/docs/` in a browser, find the
endpoint there and type its path in step 2.

## Fixed: a check-out shown under Check-In

When calculated times were not available and a day had only a check-out punch, its time was
shown under Check-In. Check-in and check-out now follow each punch's state; a day with only a
check-out shows Check-In "—" and *Missing check-in*.
