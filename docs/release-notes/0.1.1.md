# com_biotime 0.1.1 — Connect via

Adds **Connect via** to *Integration Settings → Connection*, as in the ServiceDesk Plus component.

Use it when ZKBioTime's own name only resolves inside the company network and the Joomla server
reaches it through a public address, for example:

| Server URL | Connect via |
|---|---|
| `https://zkb.mysite.com` | `api.zkb.mysite.com` (or `api.zkb.mysite.com:8443`, or an IP:port) |

Joomla opens the connection to the *Connect via* address but keeps `zkb.mysite.com` for the
certificate check and the Host header, so ZKBioTime's existing certificate stays valid and no
hosts-file or DNS change is needed on the Joomla server. *Test Connection* and *Read Certificate
Pin* go the same way.

## Repository

The source is now at https://github.com/aboarken/biotime. The extension is still `com_biotime`;
Joomla's update server and changelog links point to the new repository.

## Update

*System → Update → Extensions*, or install `com_biotime.zip` over 0.1.0. Settings are kept; there
are no database changes.
