# com_biotime 1.2.5

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**My Punches:** the titles *Punches per Month* and *Punches per Device* no longer show the year (it
is chosen in the toolbar). With one month chosen, *Punches per Device* names that month.

A site with its own language override for `COM_BIOTIME_PUNCHES_PER_MONTH` or
`COM_BIOTIME_PUNCHES_PER_DEVICE` should remove the `%s` from it.
