# com_biotime 1.2.8

Update from **System → Update → Extensions**, or install the attached package. No database changes.

**Every portal page now opens at once.** The *"Showing your data from … Updating…"* note of 1.2.6
now also covers **My Leaves**, **My Approvals** and the **Manager Dashboard**: they open with the
data they were last shown with, then update themselves in the background.

- **Manager Dashboard:** each employee's attendance is kept in the manager's own cache, so a team
  page the manager has already seen opens at once. Which employees a manager may see is always
  current, never an older copy. The printed report and the PDF always read current data.
- The first visit of a large team may take slightly longer than before; later visits are fast.
