# com_biotime 1.2.0

Update from **System → Update → Extensions**, or install the attached package. No database changes.
The package is larger (about 4 MB more): it now includes the PDF library.

**Export PDF downloads a finished PDF file.** On the Manager Dashboard, **Export PDF (A4)** and
**Export PDF (A3)** now make the PDF on the server and download it at once: no print dialog and no
printer to choose, always **landscape** and the right way up, on any browser or computer (before,
printing through *Microsoft Print to PDF* turned the pages to portrait with the table sideways).

The file has the same content as before: site name and letterhead, filters, cards and the table in
the dashboard's colours, the footer and page numbers on every page. A whole month for a large
department can take up to about 10 seconds.
