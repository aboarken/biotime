# com_biotime 0.8.0

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Your Devices** (My Dashboard, was *Devices You Used*) lists every device you use: every device
  you have punched on and every device you are registered on in ZKBioTime, with this month's
  fingerprint, face and total punches (0 for a device not used this month). Needs *Read attendance
  from: Database*.
- **Schedules show only their times** (07:30–15:30), no longer also the timetable's name below them.
- **Monthly Overview** no longer has the Missing Morning Punch and Missing Afternoon Punch tiles;
  those days count as Present there. The two cards above stay.
- **No Missing Punch tag next to Present** in My Attendance, the day details and the calendar.
  A missing check-in or check-out still shows *Missing* in its column; the Missing Morning and
  Missing Afternoon Punch cards stay.
- **My Attendance no longer has a Punches column**; open a date to see that day's punches.
