# com_biotime 1.0.1

Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Manager Dashboard is much faster**: the whole team is read in about ten database queries per
  page instead of about fifteen per employee and month. No PostgreSQL setting needs changing.
- **Manager Dashboard: dates as columns**: one row per employee, a column per date with that day's
  check-in and check-out (amber with the minutes when late or early), then Late In, Early Out and
  Total for the period.
- **My Dashboard**: thicker late/early bars, no devices with 0 punches, and the period shows
  1 August to today.
