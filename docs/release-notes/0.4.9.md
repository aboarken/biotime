# com_biotime 0.4.9 — styles stay inside the portal

Update from **System → Update → Extensions**, or install the attached package. No database or settings changes.

- **Fixed: portal styles changed the rest of the page** on templates that put `com-biotime` on
  the page `<body>` (e.g. Helix Ultimate): word wrapping, headings and pagination of the site
  header, menus and modules were affected. The portal content now carries its own
  `data-bt-root` attribute and these styles apply only inside it.
