Update from **System → Update → Extensions**, or install the attached package. No database changes.

- **Fixed "You don't have access to view departments"** for managers whose ZKBioTime user logs in
  with their e-mail address (username = e-mail, e-mail field empty).
- **Faster Manager Dashboard**: a period across two months no longer reads every employee on
  their own, and the team is no longer written to Joomla's cache on every view.
- **"You don't have access to view departments"**: the log (`administrator/logs/com_biotime.php`)
  now says why, to fix it in ZKBioTime.
